SIH26001 mapped to this repo

From the official problem to running code

The North Eastern Region faces landslides and road isolation after heavy rain. This demo is a full software walk-through of every clause, with simulated IMD / satellite / SMS pieces you can later swap for live keys.

  1. a. Collect rainfall, soil, satellite, terrain, history

    ner_landslide/feeds.py + data.py. Open a pin on the GIS map — the feed box shows each source.

  2. b. AI/ML high-risk zones

    ner_landslide/model.py Random Forest. Page: AI engine.

  3. c. Real-time alerts to district, SDMA, community

    notify.py + Operations → Dispatch. SMS is logged (plug Twilio later).

  4. d. GIS of roads, villages, infrastructure

    gis.py + home map layers and heatmap.

  5. e. Geo-tagged photo/video reports

    Field report page. store.py saves files under data/uploads.

  6. f. Dashboards: severity, roads, weather forecast, who to help first

    Operations + forecast.py + priority.py.

  7. Multilingual + low-network / offline

    English, Hindi, Assamese, Bangla alerts. PWA service worker + report queue in report.js.

Run python app.py then open http://127.0.0.1:5000.
