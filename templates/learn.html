Beginner path

Build this project in five small steps

You do not need prior AI experience. Each step is one idea, one Python file, and one thing you can point to on the live map.

  1. 1. Understand the problem (config.py)

    NER has steep hills and a strong monsoon. Landslides block roads and villages. We placed 12 imaginary but realistic monitoring sites across the eight states. Open ner_landslide/config.py and read the station list. Change a slope number, restart the app, and that site becomes more (or less) dangerous.

  2. 2. Get data (data.py)

    Real systems use IMD rainfall, GSI landslide records, and satellite slope maps. Here we simulate those sensors so you can learn without API keys. Run: 

    python scripts/01_make_data.py

    You will get a CSV: one row per site per day, with rain, slope, soil moisture, and whether a landslide happened.

  3. 3. Train a tiny AI model (model.py)

    A Random Forest is a crowd of simple yes/no trees that vote. We show it past days and the yes/no landslide column. Then it guesses the chance for a new day. Run: 

    python scripts/02_train_model.py

    Look at accuracy and “feature importance” — which clues the forest trusted most (usually 72-hour rain).

  4. 4. Turn a % into a warning (alerts.py)

    0.81 is not useful to a district officer. Colours are: Low, Moderate, High, Severe. There is also a safety net: if rain is extreme, we raise the warning even if the model is unsure.

  5. 5. Show it on a map (app.py)

    Flask serves web pages. The live map reads JSON from /api/stations. The what-if sliders call /api/what-if.

    python app.py

    Open http://127.0.0.1:5000. Click pins. Drag sliders. Read the How the AI works page.

Ideas to try next (still beginner-sized)

  • Add your hometown as a 13th station in config.py.
  • Change alert cut-offs in ALERT_LEVELS and see the map recolour.
  • Replace simulated rain with a real CSV from IMD later.
  • Send the message field to WhatsApp or SMS in a later version.
